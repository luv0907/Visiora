# Visora 3D Model Import Directory

Drop your downloaded 3D model files (`.fbx`, `.obj`, `.gltf`, `.glb`) into this directory:

### Recommended Folder Organization:
- `Assets/Art/Models/Equipment/`
  - `Voltmeter.fbx` (or `.obj`)
  - `Ammeter.fbx` (or `.obj`)
  - `Rheostat.fbx` (or `.obj`)
  - `PlugKey.fbx` (or `.obj`)
  - `Resistor.fbx` (or `.obj`)
  - `PowerSupply.fbx` (or `.obj`)
- `Assets/Art/Models/Environment/`
  - `LabWorkbench.fbx`
  - `LabStool.fbx`
  - `Glassware/` (beakers, flasks, test tube racks)

### Textures & Materials:
- Textures (`.png`, `.jpg`) will automatically import into `Assets/Art/Textures/`
- Materials will automatically generate or link from `Assets/Art/Materials/`
